# neuro_int — жестовая мышь (веб-камера)

Промышленный стандарт жестов (Ultraleap / Apple Vision Pro / самые
звёздные virtual-mouse проекты): один примитив — щипок — плюс открытая
рука. Никаких силуэтных «показал N пальцев → клик»: клик читается по
дистанции между кончиками большого и указательного, а дистанции не
ломаются наклоном руки.

## Жесты

| жест | действие |
|---|---|
| любая рука в кадре | движение курсора (точка управления — центр ладони; руки в кадре = курсор активен всегда, позы «покой» нет) |
| щипок большой + указательный | ЛКМ: нажал — держится; разжал — отпустил |
| щипок (ЛКМ) + движение руки | перетаскивание (drag) |
| два быстрых щипка | двойной клик (ОС сама распознаёт) |
| два пальца (указательный + средний, ✌) | скролл: вертикальное движение руки = колесо |
| кулак / пучок (0.3с) | «положил мышку»: курсор паркуется, ничего не срабатывает; раскрыл руку — контроль с того же места. Не вступает, пока зажат щипок |
| рука убрана из кадра | отпуск всего, курсор заморожен |

Жест ПКМ (щипок большим+средним) убран по замерам: пучок этой руки
даёт те же дистанции, что намеренный ПКМ-щипок — все 15 срабатываний
в живом логе оказались ложными. Vision Pro тоже не имеет ПКМ-щипка:
один примитив — щипок.

Как кликать: щипок = кончики большого и указательного сходятся в точку
(большой у КОНЧИКА пальца — большой, лежащий на фалангах, это кулак и
он не нажмёт). Остальные пальцы могут быть расслаблены — на клик не
влияют, и сжимать руку сильнее после щипка можно: удержание живёт до
размыкания щипка или выхода руки из кадра. Один щипок = ровно один
клик: повторный выстрел возможен только после полного раскрытия щипка
+ 0.15с паузы (анти-дребезг), короткий щипок дотягивается до 80мс,
чтобы ОС видела настоящий клик. Открыть папку = два щипка подряд
(~0.3с, рука почти на месте). Дистанции щипка считаются в стабильных
единицах (медиана-3 + сглаженная длина ладони), так что поворот руки
ребром не рождает ложных кликов.

Курсор работает как физическая мышь: **пока рука неподвижна — курсор
стоит мёртво** (заморозка по неподвижности: окно полсекунды видит, что
центр ладони не двигается — движение курсора ноль, а не «медленно
ползёт»; якорь подтягивается под шум, дрейф не копится). Устал руку или
надо «отпустить мышку» — сожми в кулак на треть секунды: курсор
припаркован, рука отдыхает/меняет позу свободно; раскрыл — ведёшь
дальше с того же места. Курсор относительный (как тачпад) **с
акселерацией** (как у обычной мыши): при захвате курсор остаётся где
был, медленное движение = точное прицеливание 1:1, быстрый взмах =
разгон до ×3 через весь экран — сенсу держи умеренной (1.5–2.5). Точка
управления — центр ладони (запястье + 4 костяшки): сгибание пальцев
при щипке и поворот кисти её почти не двигают, клик падает туда, где
курсор.

## Запуск

```bash
make run        # окно камеры + управление курсором (q — выход)
make headless   # без окна
make smoke      # 12с самопроверка камеры/GPU/детекта (мышь не трогает)
make lint       # ruff
```

Первая команда после `git clone` — `make run`: сам создаёт `.venv-edge`,
ставит зависимости и скачивает модели.

## Настройки

`config.json` в корне (создаётся сам). Сенса меняется на лету клавишами
`+` / `-` в окне (шаг 0.2, сохраняется сразу):

| ключ | дефолт | что делает |
|---|---|---|
| `sensitivity` | 1.0 | базовый гейн (0.5–8.0); точность держит акселерация — выше 2.5 обычно не нужно |
| `min_cutoff` / `beta` | 1.2 / 0.004 | One Euro: плавность против дрожи |
| `pinch_close` / `pinch_open` | 0.32 / 0.70 | гистерезис щипка (доли длины ладони) |
| `camera_index` | 0 | какая вебка |
| `mirror` | true | зеркало кадра |
| `debug_window` | true | окно предпросмотра |
| `tracking` / `clahe` | true | настройки fallback-бэкенда |
| `palm_score_threshold` / `landmark_score_threshold` | 0.4 / 0.25 | пороги fallback-детекта |

Весь кадр маппится на весь экран (никакой активной зоны); сенса — гейн
от точки захвата.

## Как это работает

1. **Захват** (`camera.py`) — `CAP_DSHOW` + MJPG + выделенный drain-поток:
   камера читается непрерывно, цикл получает только свежайший кадр
   (очередь драйвера не копит лаг). Мёртвая камера — reopen, затем
   PnP-рестарт устройства.
2. **Детект** (`mp_hands.py`) — официальный MediaPipe GestureRecognizer
   (tasks API, VIDEO-режим): ландмарки 21 точки + натренированные классы
   жестов. Watchdog в своём потоке раз в секунду перепроверяет кадр
   независимым IMAGE-распознавателем: если VIDEO-трекер залип на текстуре
   (волосы, кресло) — трекер пересоздаётся; это же единственная защита от
   «призраков» (статик-карантин остался только в ONNX-fallback).
   YuNet-гейт отсекает лицо. Коастинг 0.35с замораживает скелет
   на разрывах трекинга (без мигания костей).
3. **Жесты** (`pose.py`) — всё в долях длины ладони (wrist → middle MCP):
   щипок = дистанция большой-кончик с гистерезисом (нажатие — сразу на
   пересечении порога, ноль добавленной задержки); позы (кулак/✌/открытая)
   — по счётчикам выпрямленных пальцев, классы MediaPipe только
   подтверждают. Кулак не может НАЧАТЬ клик: входной гейт видит большой
   на фалангах (d46); удержание роняет только размыкание щипка или уход
   руки. Дистанции идут через медиану-3 и сглаженную длину ладони —
   поворот ребром и возврат руки с другой дистанции не рождают
   фантомных кликов.
4. **Скелет** — shape-lock: форма заморожена и жёстко переставляется по
   фильтрованному запястью/углу/масштабу (кости не дрожат), пересборка
   при смене позы. Дистанции щипка читаются из живых ландмарков.
5. **Команда → ПК** (`cursor.py`) — `pynput`, процесс DPI-aware; медиана-3
   + One Euro; при потере руки/выходе — принудительный отпуск всех кнопок.

| `face_detection_yunet_2023mar.onnx` (232KB) | [opencv_zoo](https://github.com/opencv/opencv_zoo/tree/main/models/face_detection/yunet) | face gate |
| `palm_detection_full_inf_post_192x192.onnx`, `hand_landmark_sparse_Nx3x224x224.onnx` | [PINTO0309 hand-gesture-recognition](https://github.com/PINTO0309/hand-gesture-recognition-using-onnx) | fallback backend (no mediapipe package) |
| `yolox_l.onnx` / `dw-ll_ucoco_384.onnx` | [yzd-v/DWPose](https://huggingface.co/yzd-v/DWPose) | unused research artifacts |

## Fresh clone (new PC)

    git clone https://github.com/LoginovLK/neuro_int.git
    cd neuro_int
    make run

That is the whole setup: `make run` creates `.venv-edge`, installs
`requirements.txt` and downloads the models itself, then starts.
`make rebuild` re-does the environment from scratch when it breaks.
No docker on purpose: the webcam is a host DirectShow device and the
cursor is moved by a host process — a container has access to neither.

`config.json` is machine-local (auto-created with defaults; tune with
the +/- keys in the debug window). `captures/`/`logs/` are local
diagnostics, never committed.
